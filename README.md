# IT Technical Labs

The focus is on developing hands-on troubleshooting, networking, system administration and security investigation skills.

- Network troubleshooting and documentation

**Folder:** `SOC-Analysis/`

### 🐧 Linux Administration

- Linux command-line practice
- File and directory management
- Users, groups and permissions
- Basic system administration
- Bash commands and scripting exercises

**Folder:** `linux/`
